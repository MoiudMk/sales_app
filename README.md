# منظومة المبيعات (Sales App) — Flutter

تطبيق نقطة بيع (POS) وإدارة مخزون، يعمل بالكامل بدون إنترنت باستخدام قاعدة بيانات محلية (SQLite).

## المميزات
- **نقطة البيع (POS):** اختيار منتجات، سلة مشتريات، خصم، إتمام البيع وإصدار فاتورة تلقائيًا مع خصم الكمية من المخزون.
- **طباعة وتصدير الفواتير PDF:** بعد كل عملية بيع (أو من سجل الفواتير القديمة)، يمكنك طباعة الفاتورة مباشرة عبر الطابعة (سلكية/لاسلكية/PDF) أو تصديرها كملف PDF ومشاركتها (واتساب، إيميل، حفظ...).
- **إدارة المنتجات والمخزون:** إضافة/تعديل/حذف منتجات، بحث، تنبيه المخزون المنخفض.
- **سجل الفواتير:** عرض كل الفواتير السابقة مع تفاصيل كل فاتورة.
- **لوحة تحكم:** ملخص مبيعات اليوم، عدد الفواتير، عدد المنتجات، تنبيهات المخزون.
- واجهة عربية بالكامل (RTL).

## المتطلبات قبل البدء
1. تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install) (الإصدار المستقر الأحدث).
2. تثبيت Android Studio (لأدوات Android SDK وبناء APK).
3. التأكد من أن الأمر التالي يعمل بدون أخطاء في الطرفية:
   ```
   flutter doctor
   ```

## خطوات التشغيل والبناء (خطوة بخطوة)

### 1) إنشاء مشروع Flutter فارغ
```bash
flutter create sales_app
cd sales_app
```

### 2) استبدال الملفات
- احذف مجلد `lib` الذي تم إنشاؤه تلقائيًا، وضع مكانه مجلد `lib` المرفق هنا.
- استبدل ملف `pubspec.yaml` بالملف المرفق هنا (احتفظ بنفس `name: sales_app` كما هو).

هيكل الملفات المرفقة:
```
lib/
  main.dart
  models/
    product.dart
    invoice.dart
  db/
    database_helper.dart
  services/
    pdf_invoice_service.dart
  screens/
    home_screen.dart
    products_screen.dart
    pos_screen.dart
    invoices_screen.dart
pubspec.yaml
```

### 3) تثبيت الحزم
```bash
flutter pub get
```

### 4) تجربة التطبيق (اختياري قبل البناء النهائي)
وصّل جوالك بالكمبيوتر (فعّل خيارات المطور + USB debugging)، ثم:
```bash
flutter run
```

### 5) خطوة إلزامية: إذن الإنترنت لنسخة الإصدار (Release)
ميزة الطباعة/التصدير تحمّل خط عربي (Noto Sans Arabic) عبر الإنترنت أول مرة فقط، ثم يُخزَّن على الجهاز ويعمل بعدها بدون نت. لكن قوالب Flutter الافتراضية تُضيف إذن الإنترنت لنسخة التجربة (debug) فقط، وليس لنسخة الإصدار (release) التي تُنتج ملف APK النهائي. لذلك **لازم تتأكد يدويًا** من وجود هذا السطر في الملف:
```
android/app/src/main/AndroidManifest.xml
```
داخل وسم `<manifest>` (قبل وسم `<application>`):
```xml
<uses-permission android:name="android.permission.INTERNET"/>
```
إذا كان السطر غير موجود، أضِفه ثم احفظ الملف. بدون هذا السطر، ستفشل الطباعة والتصدير في نسخة APK النهائية برسالة خطأ عند تحميل الخط.

### 6) بناء ملف APK
```bash
flutter build apk --release
```
بعد الانتهاء، ستجد ملف الـ APK هنا:
```
build/app/outputs/flutter-apk/app-release.apk
```
انسخ هذا الملف إلى جوالك وثبّته مباشرة (فعّل خيار "السماح بالتثبيت من مصادر غير معروفة" إذا طُلب منك).

> ملاحظة: إذا أردت تصغير حجم الملف حسب نوع المعالج، استخدم:
> ```bash
> flutter build apk --split-per-abi
> ```

## ملاحظات تقنية
- قاعدة البيانات SQLite تُنشأ تلقائيًا داخل الجهاز عند أول تشغيل، ولا تحتاج أي إعداد يدوي.
- كل البيانات محلية على الجهاز (لا يوجد اتصال بخادم خارجي)، عدا تحميل خط الطباعة العربي أول مرة (انظر الخطوة 5 أعلاه).
- الطباعة تعمل مع أي طابعة متوافقة (شبكة/بلوتوث/AirPrint) عبر حوار الطباعة الرسمي لنظام أندرويد، كما تتيح "حفظ كـ PDF" مباشرة من نفس الحوار.
- زر "تصدير PDF" يفتح قائمة مشاركة النظام (واتساب، إيميل، بلوتوث، حفظ في الملفات...).
- الخط الافتراضي مضبوط على `Cairo` في الكود (`fontFamily: 'Cairo'`) — إذا لم تضِف خط Cairo يدويًا، Flutter سيتجاهله ويستخدم الخط الافتراضي دون أي مشكلة في التشغيل. لإضافته فعليًا: نزّل خط Cairo من Google Fonts وأضِفه في `pubspec.yaml` ضمن قسم `fonts`.
